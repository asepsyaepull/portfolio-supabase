# Portfolio

Dibangun dengan Next.js, Tailwind CSS, PostgreSQL (self-hosted), dan berbagai teknologi modern untuk UI/UX yang menarik, responsif, dan dinamis.

## Tech Stack

- **Frontend**: Next.js 16, Tailwind CSS, Framer Motion
- **Database**: PostgreSQL 16 (self-hosted on VPS)
- **Auth**: Custom (bcrypt + JWT + sessions)
- **Storage**: Local filesystem
- **Deploy**: GitHub Actions → VPS (PM2 + Nginx)
